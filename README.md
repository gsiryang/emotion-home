# 情绪归处

一个移动端优先、可安装、离线可用的本地化网页应用，用于：

- 从身体感受开始识别自身情绪；
- 区分事实、脑补与他人情绪的归属；
- 在缺乏安全感时，以渐进方式练习表达观点、感受、请求与边界；
- 回顾触发模式，而不把情绪记录变成新的考核。

## 本地运行

项目不依赖第三方包。请通过本地 HTTP 服务运行，例如：

```powershell
python -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。

## GitHub Pages

将仓库发布源设为仓库根目录即可。所有数据都保存在浏览器本地，不会写入 GitHub 仓库。

## 隐私

- 无账号、无后端、无遥测；
- 默认使用浏览器 `localStorage` 保存记录；
- 可在设置中导出或清除；
- 这是自我觉察工具，不提供医学或心理诊断。

## 新增的日常支持

- **今日最小可控计划**：按设备本地日期保存唯一任务、最小完成标准和完成状态。新一天不继承未完成任务。
- **每周一件新鲜事**：周一开始新的一周，一周一个尝试，可写体验感受。没有连续打卡或失败计数。
- **先停在今天**：身体安顿 → 给预测命名 → 区分事实 → 选择今天的小动作 → 结束分析。草稿自动保存在本机；将动作设为今日计划前，已有任务时会先确认替换。
- 新数据随设置中的 JSON 导出；“清除全部记录”同时删除新增板块的数据。历史计划可在对应板块底部回看。

### iPhone 提醒事项

今日计划中展开“加入 iPhone 提醒事项”，按照页面说明在 iPhone 创建名为“情绪归处提醒”的快捷指令，用“快捷指令输入”作为“添加新提醒事项”的标题，日期／时间设为每次询问。保存任务后点击“运行快捷指令”。需要在 iPhone 上完成首次设置和权限授权，并检查实际生成的提醒。网页不读取系统提醒，也不同步完成状态。重复运行可能重复添加。无法运行时可复制任务手动添加。

协议依据：[苹果官方快捷指令 URL 文档](https://support.apple.com/zh-cn/guide/shortcuts/apd624386f42/ios)。思维练习参考：[NHS：识别并重新审视不利于自己的想法](https://www.nhs.uk/every-mind-matters/mental-wellbeing-tips/self-help-cbt-techniques/reframing-unhelpful-thoughts/)。这些功能是日常支持，不替代专业诊疗。

### 验证

运行 `node tests/support.test.cjs` 检查本地日期与跨年周界、单任务保存与完成、替换保护、文字转义、提醒链接编码和数据清除。iOS 系统提醒实际落地需在 iPhone 验证。

## 启动器

启动器与其他工具并列在首页。状态选择 → 领域选择 → 一个随机微动作 → 太难就逐级缩小 → 自己确认已经启动。

- 六个方向各有两组动作；状态决定起始难度。同一组逐级降到打开、触碰或看一眼，不跳到更难的任务。
- 常规动作上限 2–5 分钟，降级动作可以更短。即使状态还可以，也不派发多项任务。
- 计时用截止时间保存，刷新后继续；到时只提示可以停止。提前确认启动也可以，不自动计为完成。
- 完成后默认结束，额外动作需要主动选择。没有连续签到和工作完成率；本周启动次数收在完成页的折叠区域。
- “看看我现在的状态”进入六项具体信号检查，无需先意识到自己的思维变化。
- 启动记录和当前步骤在本地保存，纳入 JSON 导出和清除全部记录。
- 回归检查：`node tests/support.test.cjs`。

## 状态扫描与统一首页（v8）

首页统一呈现状态检查、三句话倾倒、启动器、今日计划、每周新鲜事、提醒和原有情绪工具。全站使用暖白与灰绿色、统一卡片、字号和焦点样式；启动器选择按钮使用紧凑三列布局。

- 六项扫描采用用户设定的 0–2 分提醒规则：总分 0–3 绿色、4–7 黄色、8–12 红色。这不是经过临床验证的量表，也不能诊断或排除风险。睡眠问最近一次，其余问过去几小时。
- 一次红色，或当天不同检查时段连续两次黄色，开启当天低负荷。同一时段重做会替换该时段检查，不增加次数。一次黄色也会先降低启动动作上限。
- 低负荷覆盖已有启动动作；今日计划变成临时的极小动作，原计划保留且不自动标完成；每周挑战暂停。长情绪练习转为短身体动作。日期变化后不延续低负荷锁定。
- 身体明显不适单独显示医疗提示，不依赖总分，不直接假定为焦虑，也不自动安排运动。参考：[NHS 呼吸不适](https://www.nhs.uk/symptoms/shortness-of-breath/)。
- “我不知道为什么难受”在本地检测不同关键词，命中两个以上给出谨慎提示。展示原文，不伪造因果链、不认证事实、不把未命中当成没有问题。
- 默认 12:00、18:00、22:00 提醒，可修改或暂停。仅在网页打开且可见时出现页面提醒；重开只提示最近一个时段，没有补做欠账。
- 关闭网页后的提醒需下载 ICS 并导入系统日历，或手动设置三个每天重复的系统提醒。文件含三个每日重复事件及提醒。导入、系统通知权限和实际到达需在设备核对；调整网页时间不修改外部日历。
- 检查、草稿、提醒设置与低负荷状态纳入导出和清除全部记录。

检查命令：`node tests/support.test.cjs`。涵盖分数边界、重复检查、跨检查点低负荷、自动降级、跨日、身体提示优先、关键词与转义、提醒时段和日历结构。当前 Browser 运行环境导入失败，未完成浏览器视觉和 iOS 日历通知实测。


## 流程衔接与稳定启动（v9）

- 每次状态检查结果都保留“启动一个小动作”和“看看发生了什么”；三句话梳理结果也可直接启动。身体提示保留，但不会隐藏通用启动入口。
- 启动器不再显示返回状态检查的链接。入口会恢复正在进行的动作；已完成或已结束时进入新的选择页。
- 重做检查不再修改已有动作、级别或计时。低负荷的新动作明确提供“轻一点”和“小一步”两级选择，多次红色不会累计降级；更小的动作由用户主动选择。
- 连续黄色触发低负荷需属于当天不同检查时段且间隔至少 30 分钟，避免短时间跨检查点反复填写被误计。红色仍保留当天低负荷提示，但不移除启动选项。
- 新增回归检查验证跳转入口、连续红色下计时不变、两级选择和短间隔去重。

## 独立模块修复（v10，替代上述旧版联动规则）

- 今日最小计划与每周新鲜事始终保留手动填写、保存、完成及回看功能，不受状态扫描或启动器限制。
- 当天出现红色时，今日计划只显示“今天不完成也没关系”的非阻断提示，不替换内容、不隐藏输入框。每周新鲜事不添加状态干预。
- 身体与情绪、分清情绪归属、练习表达恢复原来的独立流程，低负荷也不会重定向到启动器。
- 删除原有低负荷计划替换页面。回归检查覆盖红色状态下的独立编辑、启动完成不影响计划，以及三个情绪流程的正确路由。

## 六档表情心情记录（v11，替代此前自动检查提醒）

“检查提醒”现在是情绪表情弹窗；30 秒状态扫描仍可主动进入，两种记录互不影响。上午 00:00–11:59、下午 12:00–17:59、晚上 18:00–23:59，各在页面可见时提示一次。当天晚上首次打开，弹窗一次展示三个时段；任意时段可留空，关闭弹窗或按 Escape 跳过也不会反复打扰。没有打开的日期不追补。

六档使用本地 SVG 表情图片，附文字与可访问选择状态：很开心 6、开心 5、平静 4、有点低落 3、难过 2、很难过 1。点击保存后才计分。设置页支持按月查看每天已填记录的平均分、曲线与数值表；无记录日期留空、不填零、不跨缺失日期连线。心情数据随 JSON 导出，清除全部记录也会删除。

应用启动、切回前台及每 30 秒检查当前时段，关闭应用无法弹窗。可在“检查提醒”暂停。已导入的旧系统日历提醒不受网页设置控制，如不再需要，应在系统日历手动删除。
